# Scientific Writing — 20-Point Quick Checklist

Use this checklist after drafting or revising any scientific section.

1. Did I introduce any new term that is not scientifically necessary?
2. Did I rename an existing concept for stylistic variety?
3. Is the number of "core contributions" still small and memorable?
4. Can any abstract noun phrase be rewritten as a concrete verb?
5. Does each sentence have one main logical job?
6. Did I mix design facts with empirical claims?
7. Did I move from observation to causality without an isolating experiment?
8. Am I narrating numbers that are already visible in a table?
9. Does every performance claim name the metric or scope it actually concerns?
10. Did I use "demonstrate", "establish", or "prove" more strongly than the evidence allows?
11. Did reviewer-facing or defensive language leak into the manuscript?
12. Did I repeat scope caveats unnecessarily?
13. Did I use empty academic intensifiers instead of evidence?
14. Can any "Together, these results..." sentence be deleted without information loss?
15. Did I add a closing explanation merely because the paragraph felt too short?
16. Did I call a module/parameterization a "framework" without reason?
17. Are implementation details being presented as scientific novelty?
18. Did I rewrite text that was already correct?
19. Do Abstract, Contributions, and Conclusion use the same core terminology?
20. If I remove the academic-sounding adjectives, does every sentence still contain useful information?
