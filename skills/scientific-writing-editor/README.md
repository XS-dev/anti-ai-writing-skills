# Scientific Writing Editor Skill

这是一个可复用的科研论文写作/改稿 Skill 包，目标是：

- 降低 AI 写作感；
- 避免莫名其妙造概念；
- 避免论文正文写成 rebuttal；
- 保持术语和核心故事稳定；
- 强制 claim–evidence 对齐；
- 默认采用“最小必要修改”。

## 文件

- `SKILL.md`：完整 Skill 指令。
- `checklists/20-point-checklist.md`：提交前快速检查表。
- `memory-summary.txt`：适合放入 ChatGPT Memory summary 的长期写作偏好摘要。

## 使用

在支持自定义/个人 Skill 的环境中，可将 `SKILL.md` 作为 Skill 指令使用。
在普通会话中，也可以直接附上 `SKILL.md`，并要求“按这个 scientific-writing-editor skill 修改本文”。

这个 Skill 是通用科研写作规则，不绑定某篇论文、某个模型或某个研究方向。
